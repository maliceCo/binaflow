# Binaflow layout exploration

Open `index.html` to compare the three organization proposals.

- `layout1/`: Workspace. Task navigation on the left, focused work in the center, and persistent context on the right.
- `layout2/`: Expediente. A continuous task document with a local index; reading a section does not change workflow state.
- `layout3/`: Atención. The next action is the main focus, while Brief, Plan, TODO, Activity, and Changes are support documents.

All proposals use the same dark palette, readable type scale, task content, and four demonstration scenarios. The exploration changes information hierarchy and navigation, not the visual theme.

The prototypes are static HTML/CSS/JavaScript. They do not connect to Binaflow APIs or mutate application state.
